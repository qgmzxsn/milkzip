# MilkZip Android

与 Windows v0.6.0 共用解压核心的原生 Android 应用。Android 8.0（API 26）以上，支持 ARM64 手机及 x86_64 模拟器。完全离线，没有网络权限。

## 功能

- 文件管理器式浏览：手机存储、系统文件选择器、文件夹授权、搜索、排序、多选。
- 按文件内容识别：改成 `.txt`、无后缀的真实压缩包也可直接打开。
- ZIP、7z、RAR 读取；TAR、GZip、BZip2、XZ、Zstandard、LZ4（现代及 legacy）、LZMA、传统 `.Z` 等继承同一核心支持范围。
- 同目录分卷归组；经系统选择器可一次选择一组分卷，或授权其所在文件夹。
- 一键递归，最多 8/16/32 层、4/16/64 GiB；可按层选择某个分支、全部继续、结束于本层。原始文件保留，可选择保留中间包。
- 浏览压缩包目录、查看大小、完整性检查、前台后台进度与取消、部分成功报告。
- 密码本添加、修改、删除、排序、UTF-8 文本导入、明确保存；按顺序尝试；仅验证成功的临时密码可自动保存。首尾空格保留，最多 64 条，每条不超过 1024 UTF-8 字节。AES-GCM 加密，密钥保存在 Android Keystore。
- 创建 ZIP（STORE 存储模式，与 Windows 功能一致），文件夹递归、Unicode 名称、ZIP64，流式处理，不将大文件整体读入内存。
- 独立结果目录，重名自动编号；可以导出到系统授权目录、分享结果文件。浅色和深色界面，旋转时保留后台任务。

## 使用

1. “文件”→“手机存储”授予文件访问权限；或“＋”→“授权文件夹”，也可直接“选文件”。
2. 点击任意文件，按内容尝试打开。分卷请置于同目录；如果使用系统文件选择器，一次选中所有卷。
3. 点击“一键解压”立即递归到底；“选项”可调整层数、输出上限和保存位置。默认在原文件旁创建结果文件夹（直接访问）或应用的 `Results`（系统选择器）。
4. “任务”中查看报告和结果；“查看报告”可以再次导出结果。
5. 长按文件→“选择 / 多选打包”，再点“打包 ZIP”。

新增 android.2：长按文件/文件夹删除与多选删除（确认后永久删除）；补充 NSIS EXE 自解压容器识别；解压引擎在独立进程运行，异常退出显示报告并保留完成文件，后续任务可以重新启动引擎。32 层 7z 和引擎进程退出已加入自动测试。

Android 限制：所有文件权限仍不能读取其他应用受保护的私有目录；系统提供商可能只授予单个文件权限。经系统选择器打开时需要缓存副本，分卷也需要缓存。向提供商导出时先在本机保留完整结果；取消导出会保留已完成文件和本地结果，可重试。卸载应用会删除应用专属结果和密码本，重要文件请导出。Android 回收整个进程会终止任务，已完成的结果保留，但不自动续解。

原生引擎拒绝路径穿越和不安全链接；不自动执行解出的程序。普通文本并不是压缩格式；仅真实压缩数据支持按内容解压。并非所有历史或私有压缩算法都能解开。

## 构建

依赖：JDK 17+、Android SDK 35 / Build Tools 35.0.0、NDK r27c（27.2.12479018）或更新、CMake 和 make。

```sh
export ANDROID_HOME=/path/to/android-sdk
export ANDROID_NDK_HOME="$ANDROID_HOME/ndk/27.2.12479018"
sh scripts/build-android.sh
cd apps/android
./gradlew testDebugUnitTest lintDebug assembleDebug
# 已启动模拟器或连接手机时：
./gradlew connectedDebugAndroidTest
```

`ABIS=arm64-v8a sh scripts/build-android.sh` 可只编译手机架构；默认编译 ARM64 和 x86_64。所有本机库检查 16 KiB ELF 对齐。由于核心以文件路径加载独立 7-Zip 引擎，APK 使用系统安装时提取原生库的打包方式。

输出：`app/build/outputs/apk/debug/app-debug.apk`。Gradle Wrapper 固定 8.9 并校验官方 SHA-256；AGP 8.7.3、Kotlin 2.0.21。本地 debug 签名保存在 `.local/debug.keystore`，不提交到 Git。生产发布必须保管并持续使用自己的发布签名。

CI 同时在 Android 8.0 / Android 15 模拟器运行真实引擎及 UI 测试，产物包含 APK、测试报告、模拟器截图。测试不是实体手机兼容性保证；发布前仍应在真实手机验证外部 SD 卡、不同文件提供商和厂商后台限制。

许可证放在 APK 的 `assets/licenses/` 中；7-Zip 独立动态库保持 LGPL 替换能力，源码和固定校验值见 `scripts/fetch-7zip.sh`。本地 Android 代码采用仓库 MIT 许可证。
